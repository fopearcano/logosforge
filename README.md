# Logosforge
(former Storyplanner)

**A narrative operating system for structured writing.**

Logosforge helps you plan, write, and evolve your story with AI — without losing control.

---

## Overview

Most writing tools split the workflow:

- editors let you write, but not structure  
- planners organize, but don't help you write  
- AI tools generate text, but ignore narrative intent  

**Logosforge unifies writing, structure, and AI in a single system.**

---

## Features

### ✍️ Structured Writing
- Scene-based writing workflow  
- Timeline for narrative structure  
- Characters, places, and notes  

---

### 🧠 Inline AI Editing
Edit text directly inside the editor:

- Rewrite  
- Expand  
- Dialogue  

**How it works:**
1. Select text  
2. Press `Cmd/Ctrl + K`  
3. Choose an action  
4. Apply or discard  

---

### 🧩 Assistant Panel
Global AI interface:

- accessible from any view  
- context-aware (scene, outline, memory)  
- supports local and cloud models  

---

### 🧱 Narrative Structure
- Timeline view  
- Acts, chapters, arcs  
- Scene reordering  

---

### 🎯 Focus Mode
Distraction-free writing:

- centered text  
- minimal UI  
- no interruptions  

---

### 🎨 Appearance Modes
- Dark  
- Light (Green)  
- Light (Warm)  

---

### ⚡ Performance
- optimized UI updates  
- reduced rendering overhead  
- lightweight AI response caching

## Installation & run

### Requirements

- Python 3.10+
- pip

##Install & run
Download and launch Terminal in folder then run commands (MAC/LINUX, for WIN adapt python commands for creating VIRTUAL ENVIRONMENT):

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install --upgrade pip
python3 run.py
```
